# AI-Website-Project-Bakery
A modern, responsive one-page bakery website designed for a local business. It features a clean UI with sections for menu, about, gallery, featured items, and contact details. Built using HTML, CSS, and JavaScript, it focuses on simplicity, elegance, and a smooth user experience across all devices.

---

##  Features

- Responsive one-page layout (mobile, tablet, desktop)
- Clean and modern UI design
- Hero section with bakery branding and call-to-action
- About section describing the bakery
- Product/Menu showcase (cakes, pastries, bread, cookies)
- Featured items section
- Image gallery for bakery products
- Contact section with location, email, phone, and hours
- Smooth scrolling navigation
- Lightweight and fast performance

---

##  Purpose

This project was created to help a local bakery establish a professional digital presence without requiring a full-scale complex system. It focuses on simplicity, usability, and visual appeal while ensuring a smooth user experience.

It also serves as a personal learning project to improve front-end development and UI design skills.

---

##  Technologies Used

- HTML5  
- CSS3  
- JavaScript (basic interactivity)

---

##  Responsiveness

The website is fully responsive and optimized for all screen sizes, ensuring a seamless experience on mobile devices, tablets, and desktops.
