# AI-Website-Project-Bakery
A modern, responsive one-page bakery website designed for a local business. It features a clean UI with sections for menu, about, gallery, featured items, and contact details. Built using HTML, CSS, and JavaScript, it focuses on simplicity, elegance, and a smooth user experience across all devices.

##  Prompt Used

The following prompt was used to generate the website using an AI tool:

> Create a modern, elegant, one-page website for a local bakery. The website should be simple, visually appealing, and easy to navigate. Include sections such as Hero, About Us, Menu, Featured Items, Gallery, and Contact. Use a warm color palette, responsive design, smooth scrolling, and clean UI. Ensure the website is mobile-friendly and lightweight with HTML, CSS, and JavaScript.

---

##  Features

- Fully responsive one-page design  
- Clean and modern user interface  
- Hero section with branding and call-to-action  
- About section describing the bakery  
- Product/Menu showcase (cakes, pastries, bread, cookies)  
- Featured items highlight section  
- Image gallery for bakery products  
- Contact section with address, phone, email, and hours  
- Smooth scrolling navigation  
- Mobile-friendly layout

It also improved my ability to use AI tools effectively for prompt engineering and project generation. Overall, this project strengthened my front-end development skills and gave me practical experience in building real-world solutions for small businesses.
